# FROST ❄️

**Зимнее оформление и дополнительные инструменты для рабочего стола Windows.**

FROST — экспериментальное настольное приложение на WPF. Оно добавляет снег поверх рабочего стола, помогает переключаться между открытыми окнами и даёт быстрый доступ к нескольким системным приложениям.

## Что уже работает

- **Снег на рабочем столе** — прозрачный слой поверх виртуального рабочего стола, не перехватывающий клики.
- **Настройка снегопада** — плотность снежинок и скорость их движения.
- **Сохранение параметров** — настройки снега и его состояние сохраняются в профиле текущего пользователя Windows.
- **Обзор окон** — список видимых окон приложений с возможностью переключиться на выбранное.
- **Глобальные сочетания клавиш** — `Ctrl + Alt + M` открывает обзор окон, `Ctrl + Alt + N` включает или выключает снег.
- **Системное оформление окон** — тёмный режим заголовков, скругления и Mica для окон FROST там, где это поддерживает Windows.
- **Панель запуска** — быстрый запуск Проводника, Блокнота, Калькулятора и Параметров Windows.
- **Русский интерфейс** — основная навигация и окна приложения переведены на русский язык.

## Оформление

Тема FROST использует тёмную хвойную основу, клюквенные оттенки, тёплое золото и холодные ледяные акценты. На главной странице дополнительно используется новогодняя фотография по ссылке на Lifehacker: при первом запуске с доступом к интернету она сохраняется в `%LocalAppData%\\FROST\\Cache` и далее загружается локально. Если источник недоступен, приложение запускается с обычным тёмным фоном.

## Нумерация релизов

До завершения разработки используется последовательность `1.0.1`, `1.0.2`, `1.0.3` и далее. При каждом следующем выпуске меняется только последнее число. Публикация в основную ветку запускает сборку и создание предварительного GitHub-релиза с ZIP-архивом Windows x64.

## Сборка и запуск

Команды выполняются из корня репозитория:

```powershell
dotnet build .\FROST\FROST.csproj
dotnet run --project .\FROST\FROST.csproj
```

## Сочетания клавиш

| Сочетание | Действие |
| --- | --- |
| `Ctrl + Alt + M` | Открыть обзор окон |
| `Ctrl + Alt + N` | Включить или выключить снег |

## Примечания

- Слой снега не должен перехватывать мышь или клавиатурный фокус.
- Снег отображается на виртуальном рабочем столе, включая несколько мониторов.
- Производительность зависит от разрешения экранов и выбранной плотности снега.
- Системное оформление применяется только к окнам FROST. Внешние приложения не изменяются.
- Обзор окон пока показывает список, а не живые миниатюры.
